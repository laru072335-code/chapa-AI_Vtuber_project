## Overview

This is the source code for a custom AI Vtuber.
It retrieves the current comment, generates speech using Voicevox, and responds with automatically generated facial expressions.

## System Requirements and Conditions

*While we recommend using the latest versions of all components, this project is still under development, so it may not work with older versions.

- VOICEVOX must be installed.
- ollama must be installed.
- Social Stream Ninja must be installed.

Minimum System Requirements
2 GB of free RAM
2–3 GB of free VRAM

Recommended System Requirements
4 GB of free RAM
8 GB of free VRAM

## Quick Start

1. For Mac, download `MacOS_dist.zip` from the Releases page; for Windows, download `Windows_dist.zip`.
2. Download [ollama](https://ollama.com/download), [voicevox](https://voicevox.hiroshiba.jp/), and [Social Stream Ninja](https://socialstream.ninja/docs/download.html) from their respective websites.
3. On Mac, use `mac_first_install.sh`; on Windows, use `windows_first_install.ps1` to verify that the scripts are executable.
4. We recommend setting the `model` in `chapa_dist/setting.jsonc` to `gemma4:e2d`. Also, for Windows users, please configure the `voicevox_path` and `socialstream_path` settings in `chapa_dist/setting.jsonc`, specifying the respective application EXE files.
5. Create a `.env` file in the same directory and register your Social Stream Ninja session key under the name `SESSNON_KEY`. Also, enable the API. For configuration instructions, refer to [this section of the official API documentation](https://github.com/steveseguin/social_stream/blob/main/api.md#quick-start-receiving-chat-messages-python--nodejs).
6. Unzip the file. On Mac, run `chapa_dist/chapa_core.bin`; on Windows, run `chapa_dist/chapa_core.exe` to execute the application.

- Tip: You can launch the system more easily if you download the LLM you plan to use (such as `gemma4:e2d`) from Ollama in advance.

## How to Change Settings

You can change the settings by modifying the `setting.jsonc` file.
The individual configuration items are as follows:

- speaker
This sets the VoiceVox speaker. Pass an `int` value, which corresponds to the number used to specify the speaker in the VoiceVox API.

- SettingAItext
This configures the system prompts.

- model
This sets the AI model used internally. Only Ollama-compatible models are supported. Specify the model name using the syntax ```ollama run <model_name>```. However, we currently recommend using the Gemma4 family. The Gemma4 family is likely the only one that will reliably support features scheduled for future implementation.
*Note: The first startup after changing settings may take some time.

- Max_queue_size
This sets the maximum length of the `asyncio.Queue` used internally.

- sd.default.device
(Applies only when `sound_output` is set to “Python”) This configures the audio output destination. Specify it as an integer. If you’re unsure, you can check the list using ```print(sd.query_devices())```.

- sound_output
Set to “Unity” or “Python” to specify whether audio is output from the Python side or the Unity side.

- voicevox_path
This sets the path to the VoiceVox executable file, required on non-Mac environments.

- socialstream_path
This sets the path to the SocialStream executable file, required on non-Mac environments.
